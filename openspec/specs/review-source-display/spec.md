# review-source-display Specification

## Purpose

AI 답변이 어떤 리뷰를 근거로 했는지 사용자가 직접 확인해 답변을 신뢰·검증할 수 있도록 참고 리뷰 카드의 표시 방식을 정의한다.

## Requirements

### Requirement: 참고 리뷰 영역
근거 리뷰가 있는 AI 답변은 답변 하단에 "참고 리뷰" 영역을 표시하고 근거 건수를 함께 보여야 한다(SHALL). 근거가 없는 답변에는 이 영역을 표시하지 않아야 한다(MUST NOT).

#### Scenario: 근거 있는 답변
- **WHEN** 답변이 3~5건의 `sources` 를 포함한다
- **THEN** 답변 아래에 "참고 리뷰 N건" 형태의 접힌 아코디언 헤더가 표시된다

#### Scenario: 근거 없는 답변
- **WHEN** 답변에 `sources` 가 없거나 비어 있다
- **THEN** 참고 리뷰 영역이 렌더링되지 않는다

### Requirement: 아코디언 펼침과 접힘
참고 리뷰 영역은 기본적으로 접혀 있어야 하고(SHALL), 사용자가 헤더를 눌러 펼치고 접을 수 있어야 한다(MUST). 헤더는 키보드로 조작 가능하고 펼침 상태가 보조기술에 전달되어야 한다(MUST).

#### Scenario: 펼치기
- **WHEN** 사용자가 접힌 헤더를 누른다
- **THEN** 리뷰 카드 목록이 나타나고 화살표 아이콘이 펼침 방향으로 바뀐다

#### Scenario: 접기
- **WHEN** 사용자가 펼쳐진 헤더를 다시 누른다
- **THEN** 카드 목록이 숨겨진다

#### Scenario: 답변별 독립 상태
- **WHEN** 한 답변의 참고 리뷰를 펼친다
- **THEN** 다른 답변의 참고 리뷰 펼침 상태는 바뀌지 않는다

### Requirement: 리뷰 카드 내용
각 리뷰 카드는 평점(별), 제목, 본문, 작성자를 표시해야 한다(SHALL). 검색 유사도 점수가 있으면 배지로 함께 표시해야 한다(SHALL). 검증 구매 여부가 있으면 구분되는 배지로 표시해야 한다(SHALL).

#### Scenario: 평점 표시
- **WHEN** 리뷰의 평점이 4 이다
- **THEN** 5개 중 4개가 채워진 별과 숫자 평점이 표시된다

#### Scenario: 유사도 배지
- **WHEN** 리뷰에 유사도 점수가 있다
- **THEN** 카드에 점수 배지(예: "관련도 87%")가 표시된다

#### Scenario: 유사도 없음
- **WHEN** 리뷰에 유사도 점수가 없다
- **THEN** 배지 없이 나머지 정보만 표시된다

#### Scenario: 긴 본문
- **WHEN** 리뷰 본문이 길다
- **THEN** 본문은 일정 줄 수로 줄임 표시되어 카드 높이가 과도하게 커지지 않는다

### Requirement: 카드 개수 제한
참고 리뷰 카드는 한 답변당 최대 5건까지만 표시해야 한다(SHALL).

#### Scenario: 5건 초과
- **WHEN** 응답의 `sources` 가 5건을 넘는다
- **THEN** 앞의 5건만 카드로 표시된다
