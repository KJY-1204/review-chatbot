# dashboard-sidebar Specification

## Purpose

대시보드 좌측 사이드바가 서비스 정체성, 현재 데이터 모드, 샘플 데이터 인덱싱 상태, 최근 분석 질문 목록을 사용자에게 보여주고 조작할 수 있게 한다.

## Requirements

### Requirement: 서비스 타이틀 표시
사이드바 상단은 서비스 타이틀 "쇼핑 리뷰 AI 분석기"를 아이콘과 함께 항상 표시해야 한다(SHALL).

#### Scenario: 초기 렌더링
- **WHEN** 사용자가 대시보드(`/`)에 접속한다
- **THEN** 사이드바 상단에 "쇼핑 리뷰 AI 분석기" 텍스트가 보인다

### Requirement: 데이터 모드 배지
사이드바는 현재 데이터 모드를 배지로 표시해야 한다(SHALL). Mock 모드이면 "Mock 모드", 실데이터 모드이면 "실데이터 모드"를 표시하고, 두 모드는 색상으로도 구분되어야 한다(MUST).

#### Scenario: Mock 모드
- **WHEN** 현재 데이터 모드가 Mock 이다
- **THEN** 배지에 "Mock 모드"가 표시된다

#### Scenario: 실데이터 모드
- **WHEN** 현재 데이터 모드가 실데이터이다
- **THEN** 배지에 "실데이터 모드"가 표시되고 Mock 배지와 다른 색상을 사용한다

#### Scenario: 모드 조회 실패
- **WHEN** 데이터 모드를 확인하지 못한다
- **THEN** 배지는 Mock 모드로 표시하지 않고 확인 불가 상태를 나타내며 화면의 나머지는 정상 동작한다

### Requirement: 샘플 데이터 인덱싱 버튼
사이드바는 [샘플 데이터 인덱싱] 버튼을 제공하고, 버튼은 대기·진행 중·완료·실패 상태를 구분해 표시해야 한다(SHALL).

#### Scenario: 인덱싱 시작
- **WHEN** 사용자가 대기 상태의 [샘플 데이터 인덱싱] 버튼을 누른다
- **THEN** 버튼은 비활성화되고 로딩 스피너와 진행 중 문구가 표시된다

#### Scenario: 인덱싱 완료
- **WHEN** 인덱싱이 성공적으로 끝난다
- **THEN** 스피너가 사라지고 완료 아이콘과 인덱싱된 리뷰 건수가 표시되며 버튼은 다시 누를 수 있다

#### Scenario: 인덱싱 실패
- **WHEN** 인덱싱이 오류로 끝난다
- **THEN** 오류 메시지가 표시되고 사용자가 버튼으로 재시도할 수 있다

#### Scenario: 중복 실행 방지
- **WHEN** 인덱싱이 진행 중이다
- **THEN** 버튼을 다시 눌러도 추가 인덱싱 요청이 발생하지 않는다

### Requirement: 최근 분석 질문 히스토리
사이드바는 사용자가 보낸 질문을 최신순으로 목록에 표시해야 한다(SHALL). 항목을 선택하면 해당 질문이 입력창에 채워져야 한다(MUST).

#### Scenario: 질문 전송 후 히스토리 추가
- **WHEN** 사용자가 새 질문을 전송한다
- **THEN** 그 질문이 히스토리 목록의 맨 위에 추가된다

#### Scenario: 히스토리 항목 선택
- **WHEN** 사용자가 히스토리 항목을 클릭한다
- **THEN** 해당 질문 텍스트가 질문 입력창에 채워지고 입력창에 포커스가 이동한다

#### Scenario: 히스토리 없음
- **WHEN** 아직 전송한 질문이 없다
- **THEN** 목록 자리에 "아직 질문이 없습니다"와 같은 빈 상태 안내가 표시된다

#### Scenario: 긴 질문 표시
- **WHEN** 질문이 사이드바 폭보다 길다
- **THEN** 항목은 줄임 표시되어 레이아웃이 깨지지 않는다

### Requirement: 반응형 사이드바
좁은 화면에서 사이드바는 기본적으로 접혀 있고 메뉴 버튼으로 열고 닫을 수 있어야 한다(SHALL).

#### Scenario: 모바일 폭
- **WHEN** 화면 폭이 데스크톱 기준 미만이다
- **THEN** 사이드바는 숨겨지고 헤더의 메뉴 버튼을 누르면 오버레이로 나타난다
